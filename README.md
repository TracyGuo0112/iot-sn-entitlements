# IOT-SN 权益查询 Demo

面向客户的只读交互原型：手动输入 appkey 切换客户，查询 SN 权益，下载 Excel / CSV 示例并上传清单批量查询，查看导入批次逐台处理结果与关联订单，导出筛选后的 CSV。

所有数据均为虚构。本项目没有接入生产接口，没有真实登录或服务端租户鉴权，也不会发放、重置权益或执行退款。

## 本地运行

需要 Node.js 20 或更高版本，无需安装依赖。Excel 解压使用随项目提供的 fflate 浏览器模块，许可证保存在 dist/vendor/fflate.LICENSE。

```sh
npm run dev
```

打开 `http://127.0.0.1:4173`。页面初始加载第一个演示客户；点击“切换 appkey”可手动输入，或选择另一个示例。

| 客户 | 演示 appkey |
| --- | --- |
| 鹿鸣智能 | `a1b2c3d4e5f60718293a4b5c6d7e8f90` |
| 星舟科技 | `b2c3d4e5f60718293a4b5c6d7e8f901a` |

`XMSN202600004` 展示退权益后待重领，`XMSN202600005` 展示再次领取历史。两个客户使用相同 SN，部分状态不同，用于验证查询隔离。

## 业务口径

- 唯一业务键为 `(appkey, SN)`。
- 初始化产生一次领取资格；消费后不可重复领取。导入中的退权益成功可恢复一次资格，并独立记录商品额度扣减。
- 批次结果是处理时的历史快照；设备权益是当前状态，分别展示。
- 退权益与资金退款分开建模。已确认原订单列表的“退款成功”表示真实资金退款；导入的“退权益成功”表示资格恢复。
- 上传表格仅用于批量查询；本轮不提供 SN 导入、退权益或退款操作。

## 检查

```sh
npm run check
npm test
```

浏览器验证脚本位于 `tests/browser.mjs`，需要 Playwright 和 Chromium，并先启动本地服务。可使用 `PLAYWRIGHT_MODULE` 和 `PLAYWRIGHT_EXECUTABLE_PATH` 指定现有运行时。

```sh
npm run test:browser
```

详细规划见 `docs/product-plan.md`。后续接入正式接口时，需将 `dist/data.mjs` 的模拟数据查询替换为服务端请求，并在列表、详情、统计和导出接口统一校验访问凭证与 appkey 权限。
